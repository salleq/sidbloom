## SIDbloom 0.4.1

**New in 0.4.1**
- **Mute / Solo** (M, S in each voice header): hear voices alone or silence them, also while playing. Exports are not affected.
- **Copy / Paste of instruments by part:** copy an instrument and paste only the parts you tick (ADSR, waveform table, pulse, chord) into another.
- The SID-Wizard export file name is cut to 12 characters.

Also new since 0.3.1 (0.4.0): export to SID-Wizard (`.swm.prg`), ▶ From pattern, whole-track copy / paste, new song-order behaviour, delete / remove unused instruments and patterns.
