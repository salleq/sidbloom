# SIDbloom

A modern, free and open-source 3-channel SID music tracker for Windows and macOS.
Compose C64 music with a clearer interface and export real, C64-compatible `.sid` files.

**Status:** early development. Done: song model, tick-based playback engine, 6502 player, `.sid` (PSID v2) and `.prg` export, verified register-for-register against the engine in a 6502 emulator (`core/`).
Planned: Tauri/React UI, audio output, SID-Wizard `.swm` import.
